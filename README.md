# The Striper Recount

A music video and seven interactive explainers about NOAA's 2026 recount of recreational striped bass fishing, made with the American Saltwater Guides Association (ASGA).

Live site: https://luyenchou1.github.io/striper-recount/

This repository holds the built site only. It is published from a separate source project by `tools/deploy_site.sh`.
